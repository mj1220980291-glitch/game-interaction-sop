## 设计总览

### 功能背景

玩家等级是妖妖棋最基础的成长感来源。系统通过「对局 → 经验道具发放 → 升级 → 奖励领取」的闭环，提升每局对局的正反馈密度，为早期玩家提供持续的资源来源，并引导关注更深层的养成体系（部从升级、幻神解锁）。经验以道具形式由服务端在结算时直接发放，等级上限由配表控制，达到满级后不再发放经验道具。

### 核心交互

玩家在每局对局结算时，结算界面展示经验条增长动效及当前/下一级奖励卡；等级提升时触发升级特效并可连升多级。等级奖励通过"任务→等级任务"页面手动领取，列表支持横向滚动，点击任意奖励卡在中区预览奖励内容；满足等级条件后领取按钮激活，同时在任务 tab 显示红点提示。

## 01. 结算经验区域

设计稿：55:803

### 当前等级

@程序 @GUI

- 等级数字显示为「lv N」，N 为整数，左对齐显示在经验区域最左侧
- 等级数字需适配 1–3 位数，容器宽度预留最大 3 位数（满级最大可能为 3 位数）
- 满级时等级数字正常显示，不隐藏

### 经验条

@程序 @GUI @动效

#### 基础信息 - @GUI @程序

- 经验条显示当前等级经验进度，格式为「当前经验值/升级所需经验值」（如 233/1000），文字展示在经验条下方居中
- 经验条位于当前级奖励卡与下一级奖励卡之间，整行水平排列：lv数字 → 当前级卡 → 经验条 → 下一级卡 → 里程碑卡
- 满级时经验条显示为满格静止状态，文字改为「已达最高等级」，不显示经验数值

#### 升级动效 - @GUI @程序 @动效

- 结算界面打开时，经验条从对局前的值开始，以动画形式增长至本局结算后的值；动效为 VX 特效，表现为经验粒子从右侧涌入 + 光效扫光
- 升级时：经验条填满后触发爆发光效，等级数字 +1，经验条重置为 0 后从剩余经验继续填充；当局连升多级时循环播放升级特效
- 满级时：经验条不播放增长动效，直接展示满格静止状态
- 网络异常导致结算数据未返回时：经验条不播放动效，显示「结算数据获取中…」；数据返回后再触发动效（异步播放方案需与程序确认）

### 本局新增奖励卡片

@程序 @GUI

- 当前级奖励卡展示本局所在等级的奖励道具图标，卡片下方标注「N级」
- 下一级奖励卡展示下一个等级的奖励道具图标，卡片下方标注「N+1级」
- 两张卡之间用箭头连接，视觉上串联经验进度方向
- 满级时当前级卡正常展示，下一级卡区域隐藏

### 下一级奖励卡片

@程序 @GUI

- 当局连升多级时，下一级奖励卡展示本局所有升级奖励的合并预览（如连升 3 级则展示 3 次奖励合并）
- 未连升时仅展示紧接的下一个等级奖励
- 满级时此卡片区域整体隐藏

### 终局大奖卡片

@程序 @GUI

- 里程碑奖励卡显示在下一级奖励卡右侧，卡片下方标注「N级可获得」（N 为里程碑等级）
- 里程碑奖励卡样式与普通奖励卡有明显视觉区分（如更大尺寸、特殊外框）
- 满级时里程碑卡若已解锁则正常展示；若未解锁则隐藏（或置灰，与程序确认）

## 02. 等级任务页面

设计稿：55:804

### tab 栏

@程序 @GUI @拼接

- 任务主页新增「等级任务」tab，位于任务 tab 栏首位，其后依次为每日任务、每周任务、赛季任务
- 有待领取奖励时，「等级任务」tab 显示红点；无待领取时红点消失
- 任务入口（主界面跳转按钮）有待领取时同步显示红点

### 当前等级信息块

@程序 @GUI

- 页面左上区域展示：大字标题「等级任务」、当前等级数字（格式「LV N」，字号突出）、经验条、经验值（格式「当前值/满级值」）
- 经验条与经验值随玩家实时等级数据更新，不需要刷新页面
- 满级时经验条显示为满格，经验值区域显示「已达最高等级」

### 终局大奖立绘区

@程序 @GUI @美术

- 页面中央展示角色立绘预览区，默认显示当前选中奖励卡对应的内容
- 若当前选中卡为里程碑奖励卡，则展示对应大奖角色立绘 + 角色名称 + 解锁条件文字（格式「到达Lv.N可得」）
- 若当前选中卡为普通奖励卡，则展示该等级奖励道具图标及数量（替换立绘区内容）
- 默认选中状态：进入页面时高亮当前等级对应的奖励卡，中区同步展示该卡内容
- 配图：里程碑卡选中态与普通卡选中态的中区对比

### 领取全部按钮

@程序 @GUI @动效 @音频

- 「领取全部」按钮位于页面右上角
- 有待领取奖励时按钮为激活态（高亮/可点击）；无待领取时为禁用态（置灰/不可点击）
- 点击激活态按钮：批量发放所有已达等级但未领取的奖励，播放领取反馈动效，按钮随即变为禁用态
- 点击禁用态按钮：无响应

### 等级卡片列表

@程序 @GUI @拼接

#### 卡片状态

- 列表横向排列，按等级从小到大排序，支持横向滚动
- 已领取卡片：显示打钩图标，整体置灰或降低饱和度
- 当前等级卡片：白框高亮，视觉上突出为当前节点
- 已达到但未领取卡片：正常高亮显示，无打钩
- 未达到等级卡片：整体置灰，不可领取
- 里程碑奖励卡（特殊节点，如 Lv.15）：卡片尺寸更大，视觉有明显区分

#### 交互行为

- 鼠标 hover 或点击任意卡片：中区立绘/奖励预览区切换为该卡片对应内容
- 点击「已达到但未领取」卡片：触发单张奖励领取，卡片状态切换为已领取
- 点击「未达到」卡片：无法领取，中区仅展示内容，不触发领取
- 点击「已领取」卡片：中区展示内容，不可重复领取
- 进入页面时列表自动滚动至当前等级卡片位置，使其可见

### 终局大奖卡片

- 里程碑奖励卡（如 Lv.15）在列表中以更大尺寸区别于普通奖励卡
- 选中里程碑卡时，中区展示对应大奖角色立绘 + 名称 + 解锁等级文字
- 未达到解锁等级时，中区展示内容不可领取，提示当前等级距解锁的差距

## 03. 等级数字全局展示

### 等级数字组件

@程序 @GUI @拼接 @美术

- 等级数字以阿拉伯数字形式展示，适配 1–3 位数，容器设计时需预留 3 位数宽度
- 展示场景覆盖以下所有位置（规格统一，美术按场景尺寸等比缩放）：
  - 主界面：玩家头像左下/右下角，点击可跳转等级任务页面
  - 聊天（世界/附近/房间/局内）：玩家头像旁，小尺寸
  - 聊天（好友聊天）：好友头像旁，小尺寸
  - 社交（小卡）：头像下方信息区，与段位并列
  - 社交（好友列表）：头像旁信息区
  - 社交（加好友申请列表）：玩家信息区
  - 社交（黑名单）：玩家信息区，灰色显示
  - 找朋友（附近的人/一起玩过）：玩家卡片
  - 排行榜（段位榜/部从战力榜）：排名列表项
  - 生涯（个人头像区）：头像下方，含经验条
  - 生涯（头像/头像框编辑预览区）：预览区头像旁
  - 生涯（访问他人）：头像下方，展示他人等级数字，不显示经验条
- 聊天/社交/找朋友等小尺寸场景：数字宽度不超过 2 位数的容器宽度，满足 3 位数时字号适当缩小
- 主界面头像区等级数字点击跳转：需在 jumpUI.xlsx 中配置跳转目标为等级任务页面
- 配图：各场景等级数字位置示意（主界面 + 生涯 + 社交小卡三类代表性场景）
