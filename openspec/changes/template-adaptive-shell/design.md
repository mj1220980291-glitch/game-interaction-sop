## Context

部件是我们自己的库产物，项目模板只提供素材。造壳时把母版里的包边 GROUP 拆平，根框就成了固定高——内容一变它不动，渲染只能事后压高度。这里把「现有几何」翻译成自动布局参数，让部件自己会包边。

## Goals / Non-Goals

**Goals**
- 部件高度跟随内容，渲染期不再手工设高
- 几何零改动：开自动布局前后子级位置一致
- 一条规则对所有模板生效，不给单套模板写特判

**Non-Goals**
- 宽度自适应（跨模板宽度不一致，按内容猜会重排版面）
- 改样式 / 改字体 / 改间距观感
- 读取或修改项目源模板（只读约束不变）

## Decisions

### D1: 参数由现有坐标反推，而不是重设间距

开自动布局会立刻按默认间距重排。为了避免「为了自适应把版面重排一遍」，参数从当前几何算：

```
paddingTop  = min(说明栏.y, 主图.y) − 根.y
itemSpacing = 说明栏.x − (主图.x + 主图.width)
其余子级（气泡 / 标号舞台）→ layoutPositioning = ABSOLUTE
```

蛋仔实测：`paddingTop = 786`、`itemSpacing = 77`，主图仍落 `y = 786 + 21 = 807`，说明栏仍在 `786`、`1277`——像素级一致。

### D2: 只让高度 HUG

宽度是模板身份（2209 / 3382 / 3698 各不相同），按内容猜宽度会把两栏比例改掉。高度 HUG 已经解决「内容长高被截断 / 留白」这个真问题。

### D3: 拒绝而不是猜

- 说明栏排在主图之前（自动布局会左右对调）→ 记缺口，不转
- 图区与说明栏重叠（间距 < 0）→ 记缺口，不转
- 簇根有多个直接子级（判不出纵向顺序）→ 记缺口，不转
- 章节缺 `主图占位` / 说明栏槽位 → 记缺口，不转

渲染期保留 `chapter.fit` 作兜底：部件没接上链时照旧压高度，接上了就跳过（`layoutMode` 判定）。

### D4: 绝对定位只能在父级开了自动布局之后设

真机实测：父级 `layoutMode = NONE` 时给子级设 `layoutPositioning = ABSOLUTE` 会直接抛
`Can only set layoutPositioning = ABSOLUTE if the parent node has layoutMode !== NONE`。

所以顺序固定为「记下子级坐标 → 开自动布局 → 设 ABSOLUTE → 把坐标写回」。
不写回的话，开自动布局那一下已经把舞台当普通子级排过一遍，位置就漂了。

## Risks / Trade-offs

- 自动布局一开，子级 `constraints` 语义变化：固定版式的块（顶部 / 结尾）不参与转换，避免边界情况
- `paddingTop` 是静态数：源模板若日后调整首行留白，需重编才生效（可接受，本来就是一次编译产物）
- 沙盒里 `setAutoLayout` 走一次插件调用，节点少（章节根 + 子级），不会触发 10 秒上限
