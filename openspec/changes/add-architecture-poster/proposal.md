## Why

这套 SOP 的组成是五层：入口、编排、引擎、运行时、项目资产。说明书的排版是为了「边读边操作」设计的，一行一行往下读，放不下这种整体结构的表达；写进说明书只能退化成一张分层表格，看不出层级之间的关系。

同时这张图有独立的传播场景：给新组员讲这套东西怎么运转、给外部介绍我们在做什么、放进汇报材料。它需要单独打开、单独截图，而不是从说明书里滚半天截一段。

## What Changes

- 新增 `docs/architecture/index.html`，单文件海报，双击可看，断网可用
- 用椭圆堆叠表达五层：入口、编排层、引擎层、运行时、项目资产；引擎层做视觉重心
- 顶部一条输入栏（策划文档 / 设计稿 / 口头需求），右侧一条产出栏（Figma 文档 / 文风文件 / 模式库条目），虚线连到对应层
- 中间一条竖向主线，标「一轮：一份需求 → 一份交互文档」
- 说明书中删掉原来的分层表，只留一行入口链接
- 视觉走产品架构图路线：浅底、蓝色渐变、层间光晕、淡网格底纹；窄屏（≤1080）降级为卡片序列，保留信息、放弃椭圆
