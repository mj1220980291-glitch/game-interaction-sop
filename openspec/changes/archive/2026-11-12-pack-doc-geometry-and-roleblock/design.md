## 上下文

比对方法（2026-11-11 真机）：把原稿模板与渲染产物逐节点导指纹（尺寸 / 布局 / 内边距 / 间距 / 填充 / 描边 / 圆角 / 文本样式），再做差集。

结论分三层：

| 层 | 例子 | 现在由谁负责 | 结论 |
|---|---|---|---|
| 部件内 | 字体、簇间距 30、说明栏↔图示 77 | 克隆部件时原样继承 | 齐，无缺口 |
| 部件外、文档内 | 底色、章节外壳 | `docBackground` / `sectionShell` | 齐 |
| **部件外、文档级留白** | 左右内边距、块间距、结尾前留白 | **无人负责** | 缺口 |
| 包外配置 | 职能变体 key、书写契约 | 用户目录 / 人工落盘 | 缺口（易丢） |

顺带纠正一处旧判断：官方 1.14 的 `docPadding` / `rootGap` / `footerGap` **原稿就是 0**（根帧无内边距，`3690 = 子块宽`，`761+995+3573 = 5329` 无间隙），所以补齐后数值仍是 0——坑只在「留白画在文档根」的模板（蛋仔）上暴露。

## 决策

### D1｜三项留白在编译期采，不在渲染期猜

渲染期只有部件，看不到整篇文档，永远猜不出「文档根左右留了 60」「章与章之间空 60」「结尾前空 200」。唯一能看到的是编译期的原稿，所以只能在编译期采、写进包。

采集口径（全部相对原稿，单位 px）：

| 字段 | 从哪量 | 蛋仔实测 | 1.14 实测 |
|---|---|---|---|
| `docPadding` | 原稿文档根的内边距 | `{0,60,0,60}` | 全 0 |
| `rootGap` | 原稿同级块（章节/总览/顶部）之间的间距 | `60` | `0` |
| `footerGap` | 结尾块之前那块留白的高度（或与上一块的间距） | `200` | `0` |

量不到不静默：写 `gaps`，话术点名字段、后果与修法（沿用 `sectionShell` 现有格式）。

### D2｜告警按「信息是否已表达」判，不按「字段是否有值」判

现有 `sectionShell` 告警的判据是「字段缺失」——但蛋仔的黑边画在文档根，章节本来没有外壳，于是每次渲染都被催一次，属误报。

改判据：`docPadding`（或 `docBackground` + 根填充）表达了文档级留白时，不再提示 `sectionShell`。判的是**信息有没有丢**，不是**字段有没有填**。

### D3｜`placeholder` / `bubbleGrid` 明确不采

- 占位灰：默认值即可，只有深色模板里「占位块与背景对比过低」才值得记——真要处理应该走对比度告警，不是硬编码颜色
- 标号点位：标号该贴哪儿由**每篇文档**的控件决定（Phase 3 逐簇确认 `badgeAnchors`）；模板网格只是无输入时的示意位。记下来会让「示意位」看起来像「已对位」，比不记更危险

两条理由写进契约，避免下一轮又被当成「缺失字段」补回来。

### D4｜`roleBlock` 进包，解析「包优先」

职能标签的 7 个变体 key 是**模板身份的一部分**（`@GUI` 能不能变成彩色标签取决于它），放用户目录等于每次换机重配。

- `TemplatePack.roleBlock?: { variantKeys?, componentSetId?, variantPrefix?, labelTextName? }`
- 解析优先级：**包 > 用户配置（`~/.game-interaction-sop/template.json`）> 无**
- 都没有且 md 里带 `@职能` → 现有错误/告警不变（`roleBlock.variantKeys 里没有合法角色名`）

### D5｜书写契约改为「从包派生」

`md-contract.md` 的内容是包的投影（字段、槽位、列布局都由 `capabilities` / `geometry` 决定），所以**不需要单独存文件**：`figma_compile_template(phase="contract")` 随时能从包重建。文档里不再要求人工落盘，蛋仔那份丢了不影响任何流程。

同时把「`需求组` 行可省略」写进生成内容：模板顶部没有该槽位时，写了只会得到一条软告警。

## 风险

| 风险 | 缓解 |
|---|---|
| 采集口径与原稿层级耦合（不同模板层级不同） | 只认「有 padding 或有纯色填充的祖先」与「同级块间距」，与 `sectionShell` 同一套规则；量不到写 gaps 而不是瞎填 |
| 新增 `roleBlock` 字段让老包不兼容 | 字段可选，缺省走用户配置，行为不变 |
| `default.json` 也补 `roleBlock` 时 key 抄错 | 补前用 `audit_template_pack(deep)` 冒烟；只从库文件当前值抄 |

## 验证

- 单测：三项留白采集（有/无两层）、缺 id 时 gaps 话术、`docPadding` 有值不报 `sectionShell`、`roleBlock` 包优先于用户配置
- 真机：蛋仔包删掉手工补的三项后，由编译重新产出并**数值一致**（60 / 60 / 200）
- 真机：蛋仔渲染不再出现 `V2_W_PACK_GEOMETRY_DEFAULTED`，`@GUI` 仍能变成彩色标签（`roleBlock` 从包解析）
- 1.14 渲染仍为 `ok:true`，且三项留白为 0 时不误报
