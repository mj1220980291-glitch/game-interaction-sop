## 7 角色名单 + 颜色

| 角色 | 颜色 (hex) | 关注内容 → 看到这些规则就归到该角色 |
|---|---|---|
| `@程序` | `#3ADCFF` | 触发条件、状态机、数据绑定、输入处理、异常分支、刷新时机、命中判定 |
| `@GUI` | `#FF9154` | 显示位置、层级、组件状态、可读性、遮挡、信息优先级、布局密度 |
| `@拼接` | `#FFEF60` | 资源摆放、prefab 拼装、自适应布局、安全区、文本/图标绑定、引擎集成 |
| `@美术` | `#FF487C` | 立绘、模型、icon、材质、主题一致性、资源规格 |
| `@动效` | `#E121FF` | 进出场、过渡、高亮、数值变化、节奏、可打断性、飞行轨迹 |
| `@音频` | `#9E7BFF` | 点击、确认、成功、失败、解锁、获得、可中断/重复音 |
| `@策划` | `#48FF70` | 数值规则、配表字段、阈值、解锁条件、平衡、决策待定项 |

## 命名规则（强制）

- 必须写作 `@音频`，**不要**写作 `@音效`（与 Figma 模板 token 一致）
- 必须写作 `@动效`，**不要**写作 `@VX` 或 `@特效`
- 必须写作 `@程序`，**不要**写作 `@开发` 或 `@RD`

---

## 在 Markdown 中如何写

紧跟在 `### 语义簇标题` 下方独占一行，空格分隔：

```markdown
### 卡牌入口区
@程序 @GUI

- 规则 1
- 规则 2
```

至少 1 个角色，无上限。AI 根据该语义簇的内容自己挑相关角色。

## 在 Figma 模板中的实现

模板里每个"小标题"块下方有一个**横向 auto-layout FRAME**，内含 7 个预染色、预字体的 TEXT 节点，每个对应一个角色（顺序：`@GUI` `@程序` `@拼接` `@动效` `@美术` `@策划` `@音频`）。

**填充时**：

- 保留 Markdown 中列出的 `@角色` 对应的 TEXT 节点
- 删除其余 TEXT 节点
- 横向 auto-layout 会自动收拢空隙

**禁止**：

- ❌ 修改 TEXT 字符
- ❌ 修改填充色
- ❌ 调用 `set_text_range_colors`
- ❌ 重建 FRAME 结构

引擎代码已封装上述规则；skill 层不需要重复处理。
