## 簇结构约定

`###` 簇名 = 控件 / 信息块名词（`队伍排行栏`、`基础信息`、`阶段与倒计时`）。

簇内固定三段，有内容才写，顺序固定：

- `#### 显示规则`
- `#### 状态说明`
- `#### 动效说明`

约束：

- **所有 bullet 必须落在某个 `####` 下**，不留游离行（游离 + 分组混用会触发 W5）
- `状态说明` 段仍按状态行写法：`xx状态：出现条件`，冒号后不写外观、不写动效
- `动效说明` 段不写状态行，避免与 T10 混写；段内每条动效都写成 `- @动效：…`
- `显示规则` / `状态说明` / `动效说明` 命中引擎 W2 / W6 软警告，属预期输出，**不因警告改名**

## 职能标注

- 配表拆着写：表结构、字段、生效逻辑 → `@程序`；具体数值、阈值 → `@策划`
- 触发规则、判定条件 → `@程序`
- 新出资源只写「需要新出什么」，不写怎么用：
  `- @GUI：需要新出 XXX 图标` / `- @美术：需要新出 XXX 场景模型` / `- @音频：需要新出 XXX 音效`
- 一职能一条，不混写；普通 bullet 不夹带职能尾巴
